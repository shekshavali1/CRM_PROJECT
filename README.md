CRM Project
A full-stack Customer Relationship Management (CRM) web application developed using Node.js, Express.js, MongoDB, HTML, CSS, and JavaScript.

Features
User Authentication (Login & Signup)
Dashboard with Customer Statistics
Add, Edit, Delete Customers
Search Customers
Customer Status Management
Follow-up Tracking
Responsive User Interface
MongoDB Database Integration
Secure Authentication Middleware
Technologies Used
HTML5
CSS3
JavaScript
Node.js
Express.js
MongoDB
Mongoose

Installation
git clone https://github.com/shekshavali1/CRM_PROJECT.git
cd CRM_PROJECT
npm install
Run the backend:

node Backend/server.js
Open the frontend in your browser.
