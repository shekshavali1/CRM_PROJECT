# 🚀 CRM Project

A full-stack **Customer Relationship Management (CRM)** web application built using **Node.js, Express.js, MongoDB, HTML, CSS, and JavaScript**. This application helps businesses manage customer information, track follow-ups, and monitor customer status through an interactive dashboard.

---

## 📌 Features

- 🔐 User Authentication (Login & Signup)
- 📊 Dashboard with Customer Statistics
- ➕ Add New Customers
- ✏️ Edit Customer Details
- 🗑️ Delete Customers
- 🔍 Search Customers
- 📌 Customer Status Management
- 📅 Follow-up Tracking
- 📱 Responsive User Interface
- 🗄️ MongoDB Database Integration
- 🛡️ Secure Authentication using JWT

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/shekshavali1/CRM_PROJECT.git
```

### 2. Navigate to the Project Folder

```bash
cd CRM_PROJECT
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure MongoDB

Update your MongoDB connection string inside:

```text
Backend/server.js
```

Example:

```javascript
mongodb://127.0.0.1:27017/crmproject
```

### 5. Start the Backend Server

```bash
node Backend/server.js
```

Server will run on:

```
http://localhost:5000
```

### 6. Open the Frontend

Open **frontend/index.html** in your browser or use **Live Server** in VS Code.
